Installed. One step left.

Open Terminal and run:
bcc-setup

Takes about two minutes. It asks which feeds this Mac should carry, installs ffmpeg and Whisper if they are missing, and starts the service.

The audio permission prompt

If this Mac is assigned the Boston Police feed, the first capture will make macOS ask for permission to record audio from other applications. Say yes. The service captures nothing until you do, and it will keep reporting success while recording silence, so this prompt is the one thing worth watching for.

If you miss it, or click the wrong button, it is under System Settings, Privacy & Security, Screen & System Audio Recording.

This build is not signed by Apple, so macOS may also ask you to approve the service in System Settings, Privacy & Security, under a "was blocked" notice near the bottom. Click Allow Anyway, then run bcc-setup again.

Checking on it later

bcc-doctor reports what is working and what is missing, by name, with the command that fixes each one. tail -f ~/.bcc/agent.log watches it run. bcc-uninstall removes it.

A report from this install is in /tmp/bcc-install-report.txt.
