Boston Control Center, scanner agent

This installs a small background service that listens to Boston area scanner feeds on this Mac, transcribes them here, and sends the text to the newsroom dashboard.

Audio never leaves this machine. What goes over the wire is a few kilobytes of text per minute per feed.

Why it runs here and not in the cloud

Broadcastify refuses connections from datacenter IP addresses. A home or office connection works, a server does not, so the listening has to happen on a real Mac. Transcription rides along because the audio is already here.

What gets installed

Four small programs and a startup item, in /Library/Application Support/BCC. Nothing else on the system is touched.

After the installer finishes

Open Terminal and run bcc-setup. It asks which feeds this Mac should carry, installs what is missing, and starts the service. The installer cannot do that part itself, because it runs as root and the tools it needs refuse to be installed that way.
